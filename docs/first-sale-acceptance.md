# Первый опыт: попытка продажи настоящей вещи

Цель: человек публикует красивое понятное объявление, другой человек/агент находит
его и может связаться. Это не обещание совершённой сделки или наличия спроса.
География не ограничивает регистрацию: показать местонахождение и способы передачи.

## Что нужно от владельца вещи

- Название/модель, честное описание состояния/дефектов и комплектации.
- Цена и валюта, допустим ли торг. Без придуманной скидки/исходной цены.
- Населённый пункт/регион, самовывоз/доставка. Не публиковать домашний адрес.
- 3–6 настоящих фото, права на которые есть; без документов/геометок/посторонних лиц.
- Явное согласие на публичную публикацию и выбранный канал связи.

Пока предмет не выбран, web/prototype содержит только маркированный демо-макет без
реального предложения и без контактов. Не использовать AI-фото как фото продаваемой вещи.

## UX и визуальная приёмка

- Мобильный и desktop: заметные название/цена/состояние/доставка/действие «Связаться».
- Реальные фото крупно, адаптивная галерея, alt, предсказуемые пропорции без обрезки дефектов.
- Читаемая типографика, клавиатура, focus, контраст, зоны нажатия ≥44px, без переполнений.
- Draft preview до публикации; нет fake urgency/просмотров/рейтинга/верификации продавца.
- Loading/empty/error/expired/blocked/sold состояния явные; кнопка не симулирует отправку.
- Один ID/версия объявления в web и MCP; человек может пользоваться без агента.

## Функциональная приёмка до публичного теста

- Auth, owner/scopes, public projection, server-side limits, CAS и idempotency.
- Реальная загрузка медиа: allowlist JPEG/PNG/WebP; bytes/decode/dimensions/frames limits,
  re-encode и EXIF stripping; запрет SVG/HTML/remote fetch; quota/delete/recovery policy.
- Draft/private/expired/blocked не читаются анонимно даже по прямому URL/API/медиа URL.
- Privileged media links защищены, thumbnails опубликованы только после publish.
- Приватная связь с продавцом: отдельная ACL-модель, не сегодняшняя общая enrolled room.
- Жалобы, ручная модерация, квоты/anti-abuse и pause switch до публичной регистрации.
- SQLite snapshot, аддитивная миграция на копии, операторский rollback без удаления данных.
- TEST отдельный, CI green exact SHA, публичный маршрут только после согласования.

## Что считаем результатом

1. Публикация: проверенный URL + фактические одинаковые id/text/price/media в web/MCP.
2. Поиск: независимый участник нашёл карточку без знания ID.
3. Отклик: настоящий участник связался; время/канал фиксируются без публикации личных данных.
4. Итог: продано / не продано / снято; фиксирует продавец, не вывод LLM.
5. Если нет откликов: честно записать отсутствие результата и проверить охват/предложение,
   не добавлять ботов-покупателей и не объявлять пилот успешной продажей.

До этого прототип — дизайн/контракты, НЕ готовая к торговле площадка.

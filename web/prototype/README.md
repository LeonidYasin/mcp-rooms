# Дизайн-прототип первой карточки

Откройте index.html обычным браузером. Никакой установки, ключей и запуска VPS.
Полностью автономно, без CDN/аналитики/внешних изображений/сетевых запросов.

- Адаптивный desktop/mobile, dark mode по предпочтению системы.
- Поиск/категории фильтруют одну ЛОКАЛЬНУЮ демо-карточку; есть empty state.
- Кнопки контакта/агента/публикации честно открывают пояснение, а не fake success.
- Фото не подменены рисунком/AI: показано состояние до добавления настоящих фото.
- Демо-цена/локация/велосипед НЕ настоящая продажа. Нет рейтингов/счётчиков/спешки.
- Не production template: встроенные CSS/JS исключительно для автономного просмотра.
  При интеграции external assets + CSP и autoescaping maintained templates обязательны.

Это визуальная демонстрация, не готовый frontend/backend, не поиск GitHub/маркетплейса.
Реальная публикация следует docs/first-sale-acceptance.md.
